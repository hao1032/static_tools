数轴上的两条动线段 PQ 与 MN

七年级数轴动点问题 · 动画演示 + 分类讨论全解（含第 3 问的"重合减速"变式）

题目原文
如图，数轴上有 A、B、C 三个点，分别表示数 −20、−8、16。有两条动线段 PQ 和 MN（点 Q 与点 A 重合，点 N 与点 B 重合，且点 P 在点 Q 的左边、点 M 在点 N 的左边），PQ = 2，MN = 4。 线段 MN 以每秒 1 个单位的速度从点 B 开始向右匀速运动，同时线段 PQ 以每秒 3 个单位的速度从点 A 开始向右匀速运动。当点 Q 运动到点 C 时，线段 PQ 立即以相同的速度返回；当点 Q 回到点 A 时，线段 PQ、MN 同时停止运动。设运动时间为 t 秒（整个运动过程中两线段长度不变）。
(1) 当 t = 20 时，点 M 表示的数为 ______，点 Q 表示的数为 ______；
(2) 在整个运动过程中，当 CQ = PM 时，求出点 M 表示的数；
(3) 在整个运动过程中，当两条线段有重合部分时，速度均变为原来的一半；当重合部分消失后，速度恢复，请直接写出当线段 PQ 和 MN 重合部分长度为 1.5 时所对应的 t 的值。

第 (1) 问

t = 20 时 M、Q 各表示什么数

① 点 M：MN 一直向右，速度 1 单位/秒，从 −12 出发 —— M = −12 + t，代入 t = 20 得 M = 8。
② 点 Q 要先判断"走到哪一段了"。Q 从 −20 出发向右，速度 3，到 C(16) 需要 (16 − (−20)) ÷ 3 = 12 秒。 因为 20 > 12，所以 t = 20 时 Q 已经掉头往回走了，此时它从 C 往回走了 20 − 12 = 8 秒：
Q = 16 − 3 × (20 − 12) = 16 − 24 = −8
答案：点 M 表示的数为 8，点 Q 表示的数为 −8。
易错提醒：图中手写的 "40" 是错的。40 = −20 + 3×20，这是把 20 秒全部当成"一直向右"来算， 漏掉了题目里"Q 到 C 立即以相同速度返回"这个条件。只要 t > 12，Q 的表达式就必须换成 Q = 52 − 3t（t = 20 时正好是 −8）。
第 (2) 问

当 CQ = PM 时，求点 M 表示的数

第 1 步：把四个点都写成 t 的式子（分段）

MN 全程不变：N = −8 + t，M = −12 + t。 PQ 要分两段（t = 12 时在 C 处掉头）：

时间段PQMN
0 ≤ t ≤ 12（Q 向右）−22 + 3t−20 + 3t−12 + t−8 + t
12 ≤ t ≤ 24（Q 向左返回）50 − 3t52 − 3t−12 + t−8 + t

第 2 步：前 12 秒 —— 解方程

CQ 是"Q 到 C 的距离"：CQ = 16 − (−20 + 3t) = 36 − 3t（t ≤ 12 时恒为正）。
PM 是"P 到 M 的距离"，要带绝对值：PM = |M − P| = |(−12 + t) − (−22 + 3t)| = |10 − 2t|。

情况方程解是否在区间内
0 ≤ t ≤ 5（P 在 M 左边）36 − 3t = 10 − 2tt = 26✗ 舍去
5 < t ≤ 12（P 已超过 M）36 − 3t = 2t − 10t = 9.2 = 46/5✓

验算：t = 9.2 时 Q = 7.6，CQ = 16 − 7.6 = 8.4；M = −2.8，P = 5.6，PM = 8.4 ✓

第 3 步：后 12 秒 —— 解方程

Q 掉头后跑到 C 的左边：CQ = Q − 16 = (52 − 3t) − 16 = 3t − 36；
PM = |(−12 + t) − (50 − 3t)| = |4t − 62|。

情况方程解是否在区间内
15.5 ≤ t ≤ 243t − 36 = 4t − 62t = 26✗ 超过 24
12 ≤ t < 15.53t − 36 = 62 − 4tt = 14✓

验算：t = 14 时 Q = 10，CQ = 6；M = 2，P = 8，PM = 6 ✓

答案：点 M 表示的数为 −2.8（即 −14/5）或 2。

第 (3) 问

重合长度为 1.5 时的 t（重合时速度减半）

核心思路：重合部分长度的变化速度 = 两条线段的相对速度。
不重合时：速度 3 与 1；一重合，速度立刻变成 1.5 与 0.5，相对速度也跟着减半。 所以只要先找出所有"谁追上谁"的关键时刻，再逐段算出 L(t) 即可。

第 1 步：标出全部关键时刻（用相对速度算）

时刻发生了什么怎么算出来的
t = 4Q 追上 M，开始重合Q 在 −20、M 在 −12，相距 8；同向相对速度 3 − 1 = 2 → 8 ÷ 2 = 4
t = 6P 追上 M（PQ 整段进入 MN，L 达到最大 2）已重合，速度变 1.5 与 0.5，相对速度 1；P 与 M 相距 2 → 2 ÷ 1 = 2
t = 8Q 追上 N同上相对速度 1；Q 与 N 相距 2 → 2 秒
t = 10P 追上 N，重合消失，速度恢复 3 与 1P 与 N 相距 2，相对速度 1 → 2 秒
t = 15Q 到达 C(16)，掉头向左t = 10 时 Q 在 1，还要走 15 个单位 ÷ 3 = 5 秒
t = 17.5P 追上 N，两条线段相向接触，再次重合P 在 14、N 在 4，相距 10；相向速度 3 + 1 = 4 → 10 ÷ 4 = 2.5
t = 18.5Q 追上 N（L 再次达到 2）相向接近速度 1.5 + 0.5 = 2；Q 与 N 相距 2 → 1 秒
t = 19.5P 追上 M（P 已越过 M，重合开始变小）接近速度 2；P 与 M 相距 2 → 1 秒
t = 20.5Q 追上 M，重合消失，速度恢复接近速度 2；Q 与 M 相距 2 → 1 秒
t = 28.5Q 回到 A(−20)，全部停止t = 20.5 时 Q 在 4，走 24 个单位 ÷ 3 = 8 秒

答案：t = 5.5、8.5、18.25、19.75
这道题的两个大坑：
① 只想到"PQ 从后面追 MN"，得到 t = 5.5、8.5 就收笔 —— 漏掉了 Q 掉头后两条线段相向运动造成的第二次重合（对应 18.25、19.75）。
② 忘了"重合期间速度减半"。一旦减速，后面所有时刻都会被推后：比如重合结束的时刻从 7 变成 10，Q 到 C 的时刻不变（15），而最终停止时间从 24 变成 28.5。

一句话总结

这类"双动线段"题目的通用套路是：① 用"起点 + 速度 × 时间"写出每个端点的坐标（分段，掉头处是分界点）； ② 用两个端点的坐标差表示线段长度并加绝对值；③ 把"追上 / 相遇"翻译成相对速度，先锁定关键时刻，再在每一小段里做一元一次方程。 第 (3) 问多了一个"速度会变"的机关，只要抓住"相对速度决定重合长度怎么变"，它其实就是一道分段函数题。
