## 本地开发预览

本站点为纯静态页面，无需构建。但由于 `clsf-viewer` 等工具使用了 **ES 模块**（`import` / `importmap`），浏览器安全策略禁止在 `file://` 协议下加载模块，因此必须通过 **HTTP 本地服务器** 预览，不能直接双击 `index.html` 打开。

### 快速启动（任选其一）

**方式一：Python（推荐）**

```bash
cd D:/code/static_tools
python -m http.server 8765
```

然后在浏览器访问：<http://localhost:8765/>

**方式二：Node.js**

```bash
cd D:/code/static_tools
npx serve -p 8765
# 或
npx http-server -p 8765
```

**方式三：VS Code Live Server 插件**

安装 Live Server 插件后，右键根目录 `index.html` → **Open with Live Server**。

### 预览各工具

| 工具 | 地址 |
| --- | --- |
| 首页导航 | <http://localhost:8765/> |
| ICO 文字图标生成器 | <http://localhost:8765/icons-generator/> |
| CLSF 刀轨 3D 预览 | <http://localhost:8765/clsf-viewer/> |
| 认识时钟 · 时间练习 | <http://localhost:8765/clock-learning/> |
| 照片排版 · 拼版打印 | <http://localhost:8765/photo-layout/> |
| 英文单词发音练习 | <http://localhost:8765/word-pronunciation/> |

> 启动服务器时如果提示端口被占用，可用 `--bind 0.0.0.0` 或换一个端口（如 `8080`），并相应更新访问地址。
>
> 修改文件后刷新浏览器即可看到效果；如遇缓存，按 **Ctrl+F5** 强制刷新。

### 一键重启服务器（Windows）

仓库根目录提供了 `restart-server.bat`，双击即可**自动关闭占用 8765 端口的旧进程并重新启动服务器**，无需手动结束任务。

```
双击 restart-server.bat
```

脚本会：
1. 查找并终止所有占用端口 8765 的进程（解决端口冲突 / 旧服务器残留）
2. 在仓库根目录启动 Python HTTP 服务器（`0.0.0.0:8765`）
3. 终端窗口保持打开，显示服务器日志；**Ctrl+C** 或关闭窗口即可停止

> 如需修改端口或 Python 路径，编辑 `restart-server.bat` 顶部的 `PORT` 和 `PYTHON` 变量即可。

## 部署与缓存

站点通过 **GitHub 仓库 → Cloudflare Pages** 自动部署（无构建步骤，构建输出目录就是仓库根目录）。`git push` 之后要经过
「GitHub webhook → Cloudflare 排队 → 上传 → 全球边缘生效」才会真正上线，通常几十秒到两分钟。

**「改了但用户看不到」通常有两层原因，仓库里已经各做了一个对策：**

### 1. 静态资源被浏览器长时间缓存 → `_headers`

Pages 对 `.html` 默认不缓存，但对 `.css` / `.js` 会给数小时级的浏览器缓存。本站文件名不带内容 hash，
所以改样式或脚本后用户会长时间看到旧版本（`clsf-viewer` 里手工加的 `style.css?v=5` 就是被这个问题逼出来的）。

根目录的 `_headers` 把所有路径统一改成 `Cache-Control: no-cache`——**可以缓存，但每次都要回源校验**：
内容没变走 `304` 几乎不耗流量，内容变了立刻生效。有了它，新增工具时不用再手工维护 `?v=N`。

### 2. 用户页面一直开着，不会主动刷新 → `version-check.js`

`version-check.js` 在页面加载时记下当前 URL 的**响应头指纹**（`ETag` / `Last-Modified` / `Content-Length`），
之后在「页面切回前台」「窗口重新获得焦点」「前台每 5 分钟」各比对一次，发现线上变了就在右下角提示
「站点已更新 · 刷新看看」。点一下带一次性参数重新进入，绕开整页内存缓存。零配置、零维护，取不到指纹时静默失效。

新增页面时在 `</head>` 前加一行即可：

```html
<script src="/version-check.js" defer></script>
```

### 排查顺序

1. **确认部署真的跑完**：Cloudflare Dashboard → Pages → 项目 → **Deployments**，最新一条要是 `Success`，
   且属于 Production。特别检查 **Settings → Builds & deployments → Production branch 是不是 `main`**——
   如果配成了别的分支，push 到 `main` 只会生成 Preview 部署，生产域名永远不更新。
2. **确认浏览器拿到的是哪一版**（换成自己的域名）：
   ```bash
   curl -sI https://<站点域名>/clock-learning/app.js | grep -i "cache-control\|etag\|age\|cf-cache-status"
   ```
   如果 `cache-control` 不是 `no-cache`，说明 `_headers` 没生效，或被 Cloudflare 的
   **Caching → Configuration → Browser Cache TTL** 覆盖了——该项应是 `Respect Existing Headers`。
3. **区分范围**：所有设备都旧 → 部署链路问题；只有某台设备旧 → 本地/中间缓存问题（微信内置浏览器最顽固）。

## 工具一：ICO 文字图标生成器

把文字（支持中文、多个字母）渲染成 `.ico` 图标，完全在浏览器本地完成，不上传任何数据。

### 功能

- **多层文字**：可叠加多个文字层，列表越靠上的图层显示在越上层；可拖动 `⠿` 手柄调整图层顺序。
- **每层独立控制**：
  - 文字内容（含中文、多字母）
  - 字号、颜色、透明度
  - 位置 X / Y（0–256 坐标系）
  - 字体、加粗
  - **旋转**（−180° ~ 180°，绕文字中心旋转）
- **画布控制**：背景颜色、透明背景、圆角大小（圆角外区域透明）。
- **预览即所得**：右侧实时预览，并附带 64 / 32 / 16px 小图瓦片，方便检查透明与缩小的观感。
- **预览区直接拖拽**：在预览图上按住文字即可拖动改位置，会自动选中鼠标下方**最近的文字**所属图层（不要求精准点到笔画）。
- **导出 ICO**：
  - 勾选需要的尺寸（16 / 32 / 48 / 64 / 128 / 256），点「生成并下载 .ico」导出**多分辨率合集**（标准 PNG-in-ICO 封装，256 按规范存为 0）。
  - 也可在尺寸列表中单独「下载 .ico」，每个尺寸导出为仅含该尺寸的 ICO 文件。
  - 文件名使用左侧填写的「文件名」（无需额外后缀，直接得到 `你的文件名.ico`）。

### 使用方法

1. 打开工具页（`icons-generator/index.html`）。
2. 在「文字图层」区填写文字，调整颜色、字号、位置、旋转等。点「+ 添加图层」追加更多文字层。
3. 设置背景、圆角，或在「透明背景」下做镂空图标。
4. 在预览区直接拖动文字微调位置（可选）。
5. 填写「文件名」、勾选导出尺寸，点击「生成并下载 .ico」；或逐尺寸单独下载。

> 所有处理均在本地浏览器完成，图片不会发送到任何服务器。

## 工具五：认识时钟 · 时间练习（`clock-learning/`）

给小学生练习「看指针说时间」的绿皮练习册式小工具，纯前端、无依赖。

### 功能

- **指针式钟面**：SVG 绘制，一根时针 + 一根分针，走时符合真实钟表（时针会随分针连续偏移，例如 3:30 时时针停在 3 和 4 之间）。钟面上的分钟数字是 `5 10 … 55 0`——最上面写 **0** 而不是 60。
- **点数字作答**：不弹键盘。点「小时」弹出 1–12 的 **4 列 × 3 排**面板；点「分钟」弹出**两组并排**的面板——左边十位 `0–5`（3 列 × 2 排）、右边个位 `0–9`（5 列 × 2 排），两组按钮同宽同高，拼出 00–59。
  - 分钟面板**每次打开都是一次全新的选择**：十位默认选中 `0`、个位不预选任何数字；大数字显示成 `0?`（个位位置是闪动的 `?`）提示还要选个位。
  - **十位和个位都选中了，面板才自动收起**：只点十位面板会保持打开等个位；十位保持默认 `0` 时，只点个位（如 `5`）得到 `05` 也会收起。打开面板后不去动它，先前选好的答案不受影响。
  - 中途想反悔（点面板外、按 Esc、点 `×`、再点同一个格子）＝取消这次选择，**保留原来的答案**。
  - 个位还没选就想提交，不会判题：面板标题变成「分钟还差个位 → 点右边」，个位那一栏会抖一下并变暖色提醒。作答后数字位锁死。
  - 面板按整行宽度展开，**下方放不下会自动向上翻**；两边都不够时限制高度（面板内部滚动）。窄屏（≤900px）贴屏幕底部弹出，保证整块都能看见。
- **随机出题**：点时钟下方的「随机出一道题」生成一个时间（不与上一题重复），页面打开时自动出一道。
- **判题 + 分钟允许误差**：可选 0 / ±1 / ±2（默认）/ ±3 / ±5 分钟；分针接近 12 时把答案读成下一个整点也算对。
- **难度**：入门（整点 / 半点）、普通（5 分刻度）、困难（任意分钟，默认）。
- **显示开关**：数字 1–12、分钟数字、刻度线（默认全部开启），可分别隐藏——全部关掉就是「纯刻度」挑战模式。
- **就地动画讲解**（没有单独板块）：答完题后，**时钟下方**浮出「看动画讲解」按钮；点一次往前走一步，每一步都同步播放指针动画、读数提示条和讲解文字——
  1. **读分针**：分针从 12 出发一格一格走过，同步显示「走过 n 个大格 → n × 5 = 几分」的计数扇形；
  2. **读时针**：时针从 12 走到当前位置，再在「时针所在的两格之间」画出橙色高亮带并点亮两个数字，讲清「没到下一时，所以读小时」；
  3. **合起来**：两条结果合成 `h 时 m 分`，给出数字写法。
  走完三步后按钮变成「再看一遍」，可以随时重播复习。

### 布局与设置记忆

- 左栏只有一张卡片：**时钟在上**，钟表下方是**「随机出一道题」按钮**；答完题后「看动画讲解」按钮出现在它**旁边（同一行）**，讲解内容紧贴这一行下方展开，看指针和看讲解不用来回找。
- 右栏：作答区（标题「你的答案」→ 提示语 → **「小时」「分钟」并排同一行** → 提交 → 反馈 → 统计）。点数字弹出的面板按整行宽度展开。
- **显示与出题选项固定在页面最下方**（整行卡片）。
- 所有选项（显示开关、难度、允许误差）**自动保存到浏览器 localStorage**，下次打开自动恢复。

> 全部在本地浏览器运行，无网络请求。

## 工具六：照片排版 · 拼版打印（`photo-layout/`）

把多张照片拼到一张纸上打印：证件照排版（一寸 / 二寸 / 护照）、九宫格拼图、满版拼版。纯前端、无依赖，照片不上传。

### 功能

- **两种排版方式**
  - **按照片尺寸**：选一寸 / 小一寸 / 大一寸 / 二寸 / 小二寸 / 签证 / 四寸或自定义 mm，自动算出纸张能放几列几行并**整体居中**（证件照场景）。
  - **按行列平分**：给定列 × 行，单元格自动均分纸张（拼图 / 联系表场景）。
- **纸张**：4 寸、5 寸 (3R)、6 寸 (4R)、7 寸 (5R)、A4、A5、自定义 mm，横向 / 纵向可切。页边距、照片间距均为 mm。
- **单元格**：白边宽度与白边颜色（证件照常见加白边）、圆角、**裁剪铺满 / 完整显示**，可选**显示裁切线**（沿单元格四角画 L 形标记，方便对刀裁切，**默认关闭**、快速模板也不改这个开关）。
- **照片不足时循环铺满**：一张证件照自动铺满整页；关闭后不足的格子留空。
- **自动分页**：照片数超过每页格数自动分页，预览顶部出现页码切换；「导出」一次导出全部页（多页时文件名自动带页码）。
- **预览即所得**：纸张按比例缩放到预览区，画布随窗口自适应；空格子用虚线框标出。
- **直接调整取景**：在预览里按住照片拖动可平移构图（**两种填充方式都可以**：裁剪铺满时在溢出范围内平移，完整显示时照片能在格子空余内靠上 / 靠左摆），**滚轮缩放**；在下方照片列表里拖动缩略图可调整顺序，顺序即排版顺序。
- **添加照片**：按钮选择、整页拖入、直接 Ctrl/⌘+V 粘贴截图都可以。
- **输出**：150 / 300 / 600 DPI，PNG 或 JPEG，导出的像素尺寸 = 纸张 mm ÷ 25.4 × DPI（6 寸纸 300 DPI ≈ 1795 × 1205 px）；「打印」按纸张实际 mm 设置打印页面尺寸、一比一不加边距，打印的是预览里正在看的那一页。
- **设置自动保存**到浏览器 localStorage（照片不保存）。

### 快速模板

一寸 ×10（6 寸纸）、一寸 ×8（5 寸纸）、二寸 ×4（6 寸纸）、护照 ×8（6 寸纸）、A4 九宫格、6 寸满版（两张并排）——一键套用后再微调。

> 所有处理均在本地浏览器完成，照片不会发送到任何服务器。

## 工具七：英文单词发音练习（`word-pronunciation/`）

小学生英语单词跟读工具，真人发音 + 口型动画 + 分级词库，纯前端、完全本地运行（除真人发音需请求有道接口）。

### 功能

- **发音来源（可切换）**：
  - **真人 · 美音**（默认）/ **真人 · 英音**：调用有道词典发音接口，常用单词是真人录音，例句是合成音。
  - **浏览器合成**：完全离线，用 `speechSynthesis` TTS。
  - **自动兜底**：真人音频失败（离线、被墙、接口变）时自动改用 TTS，只提示一次。
- **口型动画（核心亮点）**：
  - **正脸看唇形**（双唇闭拢、圆唇、展唇、张大、咬唇）+ **侧脸看舌头**（舌尖伸出、抵上牙床、卷起、平放）。
  - 按**音标驱动**：切分音标得到音素序列（如 `/θriː/` → `θ-r-iː`），每个音素对应一个口型（viseme），按时长排成时间轴，两个视图同步变化。
  - **侧脸是教学重点**：th / l / r 这几个音在正脸几乎看不出区别，侧脸能看清舌头位置。
  - 音素提示条实时显示当前音素与中文口令（如「θ · 舌尖伸进齿间」）。
- **内置分级词库**：8 个主题（三年级上·文具/颜色/动物、三年级下·数字/身体、四年级上·食物/家庭/教室），共 128 个词，参考人教版 PEP 小学英语教材，刻意覆盖难音（th / f / v / w / r / l / 长短元音对比）。
- **两种练习模式**：
  - **卡片闯关**（默认）：逐个单词大卡片展示，emoji + 单词 + 音标 + 中文释义 + 例句，操作按钮「🔊 读单词」「🔊 读例句」「🐢 慢速看口型」「✓ 下一个」。整组练完显示完成提示 + 重新练习。
  - **词表点读**：一屏列出整组单词，点🔊播「单词 → 例句」连读，自动标记已练（淡绿底 + ✓）。
- **语速可调**：很慢 0.6x / 慢速 0.8x / 正常 1.0x / 快速 1.2x，真人音频用 `playbackRate`（慢速保留音高），TTS 用 `rate`。
- **进度独立保存**：每个主题的已练单词索引存 localStorage，换主题进度不丢。
- **显示选项**：口型动画、发音提示、音标、例句、配图 emoji、自动朗读（进入新卡片时自动读一遍）均可关闭。

### 技术细节

- **音素切分**：贪心最长匹配（`tʃ` / `dʒ` / `aɪ` 等双字符音素优先），忽略重音标记但记录位置。元音个数 ≈ 音节数，用于估算 TTS 时长。
- **口型表（viseme）**：一组数值参数（jaw 张口度、round 圆唇度、spread 展唇度、teeth 齿位、tip 舌尖位置、high 舌面高低、voiced 浊音），正脸和侧脸两个渲染函数都从这组参数算出各自的 SVG 路径，保证两者天然同步。
- **时间轴**：元音权重 1.8、辅音 0.9，按权重归一化切分总时长，每段内用 ~90ms 缓动从上一个 viseme 过渡到当前。真人音频取 `audio.duration`（留 6% 前导 + 8% 尾部余量），TTS 用 `(syllables × 0.32 + 0.35) / rate` 估算。
- **双路播放 + runId 打断**：真人优先，失败兜底 TTS；快速连点只播最后一个（照抄 `clock-learning/app.js:146` 的令牌模式）。
- **网络依赖说明**：真人发音会向有道发音接口（`dict.youdao.com/dictvoice`）发送要朗读的单词/例句文本，页面已加 `<meta name="referrer" content="no-referrer">`。**这是本站唯一有网络请求的工具**；选「浏览器合成」完全离线。

### 扩展词库

词库在 `words.js`，格式：

```js
window.WORD_BANK = {
  '主题名': [
    { word: 'pen', phonetic: '/pen/', meaning: '钢笔', emoji: '🖊️', sentence: 'This is my pen.' },
    // ...
  ]
};
```

**音标必须只用 `app.js` 里 `PHONEMES` 收录的符号**（tʃ / dʒ / θ / ð / ʃ / ʒ / ŋ / 长元音 iː / uː / ɑː / ɔː / ɜː / 短元音 ɪ / e / ʊ / ɔ / ə / 双元音 aɪ / aʊ / eɪ / oʊ / ɔɪ 等），否则口型会退化成中性。新增主题只需往 `WORD_BANK` 追加，代码逻辑不用动。

> 口型按音标推算，不是波形对齐；用于示意发音部位，不等于录音本身。

## 技术说明

- 纯 HTML / CSS / 原生 JavaScript，无框架、无第三方依赖。
- **全站唯一的网络请求**：`word-pronunciation` 工具在选「真人发音」时会向有道词典发音接口请求音频，只发送要朗读的单词/例句文本；其余工具零请求。
- ICO 采用标准 **PNG-in-ICO** 封装（ICONDIR + ICONDIRENTRY + PNG 数据，小端字节序），Windows 与浏览器均兼容。
- 坐标 / 字号 / 圆角基于 256×256 虚拟画布定义，导出时按比例缩放到各目标尺寸。
