绝对值连等式 · 动画讲解

2027 个绝对值全都相等，求 x1 − 2x2 − 3x3 的值

看着像要解 2027 个未知数，其实只用到三件事：把式子全加起来、看清「奇数」、代入两次。建议先选「从 3 个数开始」，用具体数字把方法看明白。

给七年级的读法：别被 2027 吓到。下面默认用「只有 3 个数」的小题目，每一步都算成看得见的具体数字；看懂之后再把 3 换回 2027。两个版本方法一样，答案都是 −3。
原题长这样（先不用看，点开 / 收起）
已知 x1 + x2 + ⋯ + x2027 = ½ × (1 + 2 + ⋯ + 2027)
并且 |x1 − 3x2 + 1| = |x2 − 3x3 + 2| = ⋯ = |x2026 − 3x2027 + 2026| = |x2027 − 3x1 + 2027|
求 x1 − 2x2 − 3x3 的值

注意最后一项：下标绕回 x1，常数是 2027，正好和项数一致。题目里 2027 个数的下标是首尾相接的环。

为什么 x₂+x₃+x₁ 也等于 3？它只是把 x₁+x₂+x₃ 换了个顺序，加法换顺序结果不变；题目已经告诉我们这个和是 3。
第 4 步 · 3 个「一样大」的数，加起来能等于 0 吗？
假设每个盒子的绝对值是 2，里面只能是 +2 或 −2。把所有搭配都列出来：
+2 + 2 + 2 =6
+2 + 2 − 2 =2
+2 − 2 − 2 =−2
−2 − 2 − 2 =−6
一个都不等于 0！因为 3 是奇数，+2 和 −2 没法两两配成对。
所以「一样大的那个数」只能是 0：三个盒子里全都是 0。
换成 5、−5 或任何不是 0 的数都一样，总会多出一个落单的。想自己点着试？下面有「凑 0 挑战」。
第 5 步 · 绝对值外壳可以拿掉了
只有 |0| = 0。所以每个盒子里面就是 0，绝对值号直接擦掉：
盒子①：x₁ − 3x₂ + 1 = 0 → x₁ = 3x₂ − 1
盒子②：x₂ − 3x₃ + 2 = 0 → x₂ = 3x₃ − 2
盒子③：这次用不上，先放一边
题目问的式子只用到 x₁、x₂、x₃，有这两个式子就够了！
第 6 步 · 像换零件一样，把 x₁、x₂ 换掉
要算：x₁ − 2x₂ − 3x₃
① 把 x₁ 换成 (3x₂ − 1)： (3x₂ − 1) − 2x₂ − 3x₃ = x₂ − 1 − 3x₃
② 把 x₂ 换成 (3x₃ − 2)： (3x₃ − 2) − 1 − 3x₃ = −3
3x₃ 和 −3x₃ 正好抵消，x₃ 不见了，只剩 −3 ！
这里只用到「代入」：把等号右边整块塞进另一个式子里，七年级已经学过，不是新知识。
第 7 步 · 不放心？把真的 x 代回去验一遍
由三个方程能解出：x₁ = 17/13，x₂ = 10/13，x₃ = 12/13。代回去看看：
x₁ + x₂ + x₃ = (17+10+12)/13 = 39/13 = 3✓
盒子① = 17/13 − 30/13 + 1 = 0，盒子② = 10/13 − 36/13 + 2 = 0✓
x₁ − 2x₂ − 3x₃ = (17 − 20 − 36)/13 = −39/13 = −3✓
全对！说明前面不是变魔术，答案确实是 −3。

STEP 0 · 把长链条拆成 2027 个小盒子
|x1 − 3x2 + 1| = |x2 − 3x3 + 2| = ⋯ = |x2026 − 3x2027 + 2026| = |x2027 − 3x1 + 2027|
↓ 每个绝对值里，装的是同一个模样的小式子 ↓
记 Ai = xi − 3xi+1 + i （i = 1 … 2026），最后一项 A2027 = x2027 − 3x1 + 2027
下标是循环的：把 x2028 看成 x1，2027 个式子就写成了统一的形式。这个「环」是下一步求和的关键。
STEP 1 · 绝对值相等，里面只有两种可能
|A1| = |A2| = ⋯ = |A2027| = c  (c ≥ 0)
逐个翻牌：把绝对值号拿掉，每个盒子只能是 +c 或 −c
结论 Ai ∈ { +c, −c } 共 2027 个，正负各几个还不知道
别急着擦绝对值号。「|A₁| = |A₂|」只能推出 A₁ = ±A₂，不能推出 A₁ = A₂。现在连 c 是不是 0 都还不知道。
STEP 2 · 把 2027 个 Aᵢ 全部加起来
全部相加 ΣAi = A1 + A2 + ⋯ + A2027
拆成三堆 (x₁ + x₂ + ⋯ + x₂₀₂₇) − 3 (x₂ + x₃ + ⋯ + x₂₀₂₇ + x₁) + (1 + 2 + ⋯ + 2027)
橙色括号里是同一批数换了个顺序：{x₂, x₃, …, x₂₀₂₇, x₁} 与 {x₁, …, x₂₀₂₇} 只是排队方式不同，和完全相等。
于是每个 xᵢ 都拿到「+1 份」和「−3 份」，净得 −2 份 ↓
i = 1 + x₁− 3x₁ →− 2x₁
i = 2 + x₂− 3x₂ →− 2x₂
⋮每一个 xᵢ 都一样，包括最后那个绕回来的 x₁
合起来 ΣAi = −2 (x1 + ⋯ + x2027) + S = −2Σx + S 其中 S = 1 + 2 + ⋯ + 2027
STEP 3 · 代入题目给的和，总和居然是 0
S = 1 + 2 + ⋯ + 2027 = 2027 × 2028 / 2 = 2 055 378
Σx = ½ S = 1 027 689 （这就是题目第一行的条件）
ΣAᵢ = −2 × 1 027 689 + 2 055 378 = −2 055 378 + 2 055 378 = 0
✓ 2027 个数 A₁, A₂, …, A₂₀₂₇ 加在一起 恰好等于 0——这个 0 是后面所有推理的支点。
题目给的「和 = ½(1+2+⋯+2027)」不是随便写的：它正好让 −2Σx + S = 0。
STEP 4 · 2027 是奇数，逼出 c = 0
设 k 个 +c、2027 − k 个 −c，则 ΣAi = c·k − c·(2027 − k) = c (2k − 2027)
用 7 个方块示意：正负两两抵消，因为总数是奇数，永远会剩一个
2k − 2027 是奇数，不可能等于 0  →  若 c > 0，则 ΣAᵢ ≠ 0，与上一步的 ΣAᵢ = 0 矛盾
所以只能是 c = 0  ⇒  每个 |Aᵢ| = 0  ⇒  所有 Aᵢ = 0。
「奇数」就是题眼。如果项数是偶数，正负各占一半就能凑出 0，这一步就推不动了。下方的实验台可以自己试。
STEP 5 · 绝对值全部脱掉，但只用前两个式子
A1 = 0 ⇒ x1 − 3x2 + 1 = 0 ⇒ x₁ = 3x₂ − 1 第 1 个方程
A2 = 0 ⇒ x2 − 3x3 + 2 = 0 ⇒ x₂ = 3x₃ − 2 第 2 个方程
剩下的 2025 个方程 一个都用不上，也不用真的解出每个 xᵢ
真要去解这个 2027 元方程组，会出现 32027 这样的天文数字；而要求的式子只涉及 x₁, x₂, x₃，两次代入就够了。
STEP 6 · 两次代入，未知数自己消掉
目标 = x1 − 2x2 − 3x3原式
= (3x2 − 1) − 2x2 − 3x3 把 x₁ 换成 3x₂ − 1
= x2 − 1 − 3x3合并 3x₂ − 2x₂
= (3x3 − 2) − 1 − 3x3 把 x₂ 换成 3x₃ − 2
= 3x3 − 2 − 1 − 3x3 含 x₃ 的两项抵消
= −3x₃ 完全消失，答案与 xᵢ 无关
STEP 7 · 答案与复盘
x1 − 2x2 − 3x3 = −3
① 循环求和 → ΣAᵢ = 0→ ② 项数是奇数 → c = 0→ ③ A₁、A₂ 两次代入 → −3
看起来是 2027 元方程组，实质只考了三件事：循环下标的求和、奇偶性、代入消元。换任意奇数 n、系数不变，答案仍然是 −3。

完整推导（进阶 · 用字母写，可收起）

记 S = 1 + 2 + ⋯ + 2027 = 2027 × 2028 / 2 = 2 055 378，题设 Σx = S/2。把下标看成循环（x₂₀₂₈ = x₁），定义

① 统一记号 Aᵢ = xᵢ − 3xᵢ₊₁ + i（i = 1…2027），题设即 |A₁| = |A₂| = ⋯ = |A₂₀₂₇| = c。
② 全体求和 Σ Aᵢ = Σ(xᵢ − 3xᵢ₊₁) + Σ i = (Σx − 3Σx) + S = −2Σx + S。这里用到 Σxᵢ₊₁ = Σxᵢ（循环下标只是换序）。
③ 代入已知 −2 · (S/2) + S = 0，即 ΣAᵢ = 0。
④ 奇偶性 每个 Aᵢ = ±c。设其中 k 个取 +c，则 ΣAᵢ = c[k − (2027 − k)] = c(2k − 2027)。因 2027 为奇数，2k − 2027 ≠ 0；又 ΣAᵢ = 0，故 c = 0，从而所有 Aᵢ = 0。
⑤ 取前两式消元 x₁ = 3x₂ − 1，x₂ = 3x₃ − 2，于是
x₁ − 2x₂ − 3x₃ = (3x₂ − 1) − 2x₂ − 3x₃ = x₂ − 1 − 3x₃ = (3x₃ − 2) − 1 − 3x₃ = −3。

补充：由 2027 个 Aᵢ = 0 组成的循环线性方程组确实有唯一实数解（系数矩阵的行列式为 1 − 3²⁰²⁷ ≠ 0），且该解自动满足 Σx = S/2，与题设相容；只是求它完全没有必要。

进阶：四个最容易踩的坑

坑 1

看到 绝对值相等 就写成里面相等。实际上可能是相反数，必须先靠「总和 = 0 + 项数为奇数」把 c 逼成 0，才能脱掉绝对值号。

坑 2

求和时把最后一项 x₂₀₂₇ − 3x₁ + 2027 漏掉或写成 −3x₂₀₂₈。下标是绕回 x₁ 的环，正因为绕回来，Σxᵢ₊₁ = Σxᵢ 才成立。

坑 3

忘了用「2027 是奇数」。若项数为偶数，正负各一半就能让 ΣAᵢ = 0，此时 c 未必是 0，后面全部推不出来。

坑 4

硬去解 2027 个未知数。分母会出现 3²⁰²⁷；题目只问 x₁ − 2x₂ − 3x₃，用头两个方程两次代入即可。
